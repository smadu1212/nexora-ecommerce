# NEXORA — Premium E-Commerce UI

A responsive dark-themed e-commerce storefront built with **HTML, CSS, and vanilla JavaScript**. Designed as a beginner-friendly frontend portfolio project.

## Features
- Premium dark UI with responsive layouts
- Six sample tech products
- Live product search, category filter, and price sorting
- Interactive cart with quantity controls and subtotal
- Cart saved in browser localStorage
- Mobile-friendly layout

> **Demo project:** This storefront does not process real orders or payments. Product listings and prices are fictional samples.

## Tech Stack
HTML5 · CSS3 · JavaScript (ES6) · Browser localStorage

## Run Locally
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. No installation or build process required.

## GitHub Pages Deployment
1. Push all project files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then **Save**.
5. Wait for GitHub Pages to publish your site. Your URL will typically be `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`.
